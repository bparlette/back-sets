# Back Sets

**1,000 iconic movie scenes, cartoon scenes, and TV sets** — the famous frames and rooms, collected.

The sibling of [Back Roms](https://github.com/bparlette/worlds): where Back Roms collected the *worlds* of games, Back Sets collects the places of film and television — the cantina, Central Perk, the Enterprise bridge, Monica's apartment — each as the single composed image audiences remember it by.

## The rules
- One composed image per entry: the scene's famous frame, or the set pictured whole. No collages, no posters, no title cards.
- Fame ranks everything — the scenes and sets a general audience names instantly come first.
- Every image URL is verified to load before it is banked.
- Reference gallery: all artwork © its respective owners, shown for reference and study.
